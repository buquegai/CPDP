# V18 多源项目验证与同模型阈值集成

基线：v16 / 9f90f5526a55。本实验是独立候选版本，不代表替换基线。

## 目的与假设

消除“选模模型确定阈值、全源重新初始化模型应用阈值”的跨模型衔接；
减少预测结果对随机一个验证源项目的依赖。
假设是 MCC、F1、G-mean 的稳定性可能改善；并不保证 AUC/AUPRC 同时提高。

## 算法

对每个目标项目及每个预测种子，枚举同族的所有源项目：

1. 留出一个完整源项目作为验证集，其余源项目为该折训练集。
2. IPGDO 的预处理、物理约束拟合、扩散训练和增强只使用该折训练项目。
3. 保留该目标的 v16 最低损失过采样种子，增强结果独立缓存并跨预测种子复用。
4. KAN-JEPA 使用该折训练源与真实无标签目标特征训练；归一化只拟合真实训练源。
5. 在留出项目的真实样本上依据验证 BCE 选择最佳检查点，并选择 G-mean 阈值 t。
6. 同一个最佳检查点预测真实目标，不再执行全源重训练。
7. 对每折概率 p 做连续单调变换：q = p(1-t) / [p(1-t) + (1-p)t]。
   此变换满足 q >= 0.5 当且仅当 p >= t。对各折 q 等权平均，最后以 0.5 分类。
   融合分数是决策分数，不能称为已校准的缺陷概率。
8. 统一评价器在预测完成后才使用目标标签计算六项指标。

每折独立选择轮数，无跨折统一 epoch 的选择，也不在训练内样本上重新选阈值。
各折使用 v16 的 selection_seed = prediction_seed + 104729；依次运行以控制显存。
ReLink 两个源项目形成两折，每折一个训练源及一个独立验证源，不触发旧 fit_predict 的双源检查。

## 实验规模与固定参数

25 个目标项目 × v16 的 10 个预测种子 = 250 组最终结果。
每个种子共 178 个折模型，合计 1780 折；各目标依次完成一个种子，再进入下个种子。
保持 ratio=0.7、Chebyshev degree=4、shared_augmented_source、六项损失、
160 轮预训练、300 轮联合训练上限、耐心 25、原 warmup_cosine 调度及其 50 轮衰减周期。
配置中的 refit_all_sources 显式设为 false。其余预测和过采样参数与 v16 逐项比较。
v16 的原实现、启动器、配置、缓存和正式结果不覆盖。

## 输出与恢复

入口：run_v18_multisource.py。预检使用 --dry-run；四数据族短训练检查使用 --smoke。
实现位于 tools/v18_multisource.py；由该入口在进程内注册到统一方法接口。
运行目录由全部代码和配置指纹决定，位于 outputs/server_runs/formal/full/v18_multisource_<hash>/。

- manifest.json：配置/代码指纹、折清单、进程号、状态、完成时间。
- runs/ 和 predictions/：标准结果 JSON、评价器 NPZ；可沿用总表统计流程。
- summary/：每种子任务表、项目均值、族均值及总体均值，注明种子覆盖率。
- artifacts/augmentation/：每折只包含训练源的增强缓存及数据签名。
- artifacts/folds/：每折 model.pt、result.json、predictions.npz、batch_losses.jsonl。
  保存真实源验证标签/分数、目标无标签分数和行号、逐轮验证损失、阈值及实际轮数。
- ensemble_predictions.npz：全部原始折分数、阈值中心化分数、原始均值及最终分数。

相同代码/配置/数据签名的成功折可续用，签名冲突拒绝复用；失败立即停止并留存错误。
重复启动受进程锁保护。模型检查点配合对应增强缓存、配置与 scaler 可恢复推理。
源码快照保存于 backups/v16_before_multisource_20261006T063845Z/。

## 检验边界和限制

v16 过采样种子来自原完整源集合的无目标标签损失选拔，没有重新在各折内选种子。
因此折内拟合严格排除验证项目，但继承的种子超参数并非完全嵌套选拔；需如实报告。
沿用 v16 的 master-style 数据清洗协议，本实验未变更原有清洗规则。
选择 checkpoint 和阈值共用源验证项目，源验证分数不能作为无偏性能估计。
真实目标指标才用于方法评估，不用于反选折、权重、种子或项目集合。
集成结构与验证隔离同时改变，收益不能单独归因于阈值；后续可从保存的原始均值分数做消融。
训练成本随折数增加；每个折模型少使用一个源项目，可能牺牲部分排序能力。

## 验证要求

检查阈值映射单调性/边界、源验证项目隔离、ReLink 单训练源、同一模型验证与预测、
数据变化后的拒绝复用、四数据族短训练、保存预测与融合公式/六项指标一致。
正式启动前再次验证 v16 快照未变。正式结果未完成前不覆盖本地对比表，不提交 Git。
